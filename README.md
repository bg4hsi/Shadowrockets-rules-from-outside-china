# Shadowrocket 回国规则 / Rules for Accessing China from Abroad

[中文介绍](#中文介绍) | [English introduction](#english-introduction)

## 中文介绍

用于从海外访问中国大陆部分服务的 Shadowrocket 规则仓库。当直连速度较慢时，可结合自行配置的 VPS 中转使用；规则保存在仓库的 `backchina` 文件中。实际访问效果取决于 VPS 位置和网络线路。

## English introduction

A Shadowrocket rule repository for accessing selected services in mainland China from abroad. The rules can be used with a separately configured VPS relay when direct connections are slow. The rule list is stored in the repository's `backchina` file. Actual performance depends on the VPS location and network route.

国外访问国内某些服务太慢了，通过vps中转一下
